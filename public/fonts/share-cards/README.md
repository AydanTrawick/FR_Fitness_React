# Card typography

Barlow Condensed (Bold and Black Italic) and IBM Plex Mono (Medium) are bundled locally for consistent PNG previews and downloads. Both use the SIL Open Font License; each family’s original OFL.txt is included alongside the font files.

Sources: https://github.com/google/fonts/tree/main/ofl/barlowcondensed and https://github.com/google/fonts/tree/main/ofl/ibmplexmono.
